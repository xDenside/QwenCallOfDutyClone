# STRIKE COMPOUND

A browser FPS built to the visual bar of Call of Duty: Modern Warfare (2019).
Three.js, fully procedural assets, golden-hour desert compound, pooled FX, harsh-critic QA loop.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm run build && npm run preview   # optimized build at http://localhost:4173
npm run capture -- --name foo --pos 0,2,30 --look 0,1.5,0   # headless screenshot
```

See `CONTRACT.md` for system architecture and agent ownership rules.
